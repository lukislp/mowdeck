# This list is the single source of truth for every image default in the Dockerfiles, in
# infra/compose (docker-compose.yml, .env.example) and in CI. The workflow
# .github/workflows/mirror-images.yml copies each source (all architectures) to
#   ghcr.io/<owner>/mowdeck-mirror/<alias>:<tag>

# (tools/repo-checks/tests/test_images.py keeps them in sync), then run the mirror workflow.
